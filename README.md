🏥 Zeecare – Full Stack Hospital Management System
Zeecare is a robust, full-stack web application designed to streamline healthcare operations, bridge the gap between doctors and patients, and eliminate manual paperwork. Built using the MERN stack, it provides an intuitive platform for efficient appointment tracking, patient-doctor interactions, and centralized medical records.

🔗 Live Demo: (https://frontproject.onrender.com/)

🚀 Key Features & Impact
⚡ Optimized Scheduling Workflow: Engineered an automated booking system that enables a 40% faster scheduling workflow compared to traditional methods.

📂 Centralized Digital Records: Implemented secure, full CRUD (Create, Read, Update, Delete) operations for patient, doctor, and appointment data, reducing manual administrative effort by 50%.

👥 Role-Based Portals: Developed dedicated, secure dashboards for both Patients and Administrators:

Patient Portal: Seamless doctor selection, appointment booking, and real-time status tracking.

Admin Portal: Centralized control center for managing doctor availability, approving/scheduling appointments, and monitoring overall system status.

🌍 100% Accessibility: Crafted an inclusive, responsive user interface ensuring smooth navigation and feature access for 100% of registered users across mobile and desktop devices.

🛠️ Tech Stack
Frontend:

React.js (Vite)

Tailwind CSS (or whichever CSS framework you used, e.g., Bootstrap / Material UI)

React Router DOM

Backend:

Node.js

Express.js

JSON Web Tokens (JWT) for Authentication

Database:

MongoDB & Mongoose

🗺️ System Architecture & Workflow
Authentication: Users sign up/log in as either a Patient or an Admin.

Dashboard: * Patients view available doctors, book open time slots, and check their appointment history.

Admins oversee all incoming requests, assign/confirm doctors, and update appointment statuses (Pending, Confirmed, Canceled).

Database Synchronization: Every action instantly updates the centralized MongoDB database, ensuring real-time data accuracy across all portals.
